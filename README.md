# 🚀 Developer Portfolio

Personal portfolio developed to showcase my skills, projects, services, and experience as a Fullstack Developer.

## 📌 About

This project was created to present my professional profile and highlight some of the projects I have developed throughout my journey as a developer.

The portfolio includes information about my skills, featured projects, services, and contact channels.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Google Fonts
* SVG

```text
.
```

## ✨ Features

* Responsive portfolio layout
* Hero section with personal introduction
* Technology badges
* Featured projects section
* Services section
* Social media and contact links
* Hover effects and visual interactions
* SEO-friendly HTML structure

## 📸 Sections

### Hero

Introduction with personal information, professional title, and main technologies.

### Projects

Showcase of featured projects with images, names, and descriptions.

### Services

Presentation of the development services offered.

### Contact

Social media and email links for professional contact.

## 🎯 Purpose

The main goal of this project is to create a professional online presence and provide an easy way for recruiters, clients, and other developers to learn more about my work.
